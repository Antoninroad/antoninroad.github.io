Ton appli en une phrase avec Google AI Studio

Le mode Build code une appli à partir d’une description, et te la montre en direct. Le pas à pas, 3 idées d’applis à tester, et ce qui peut devenir payant.

Ce que c’est

Google AI Studio a un mode Build : tu décris l’appli que tu veux, et Gemini la code devant toi. Pas besoin de savoir programmer pour un premier prototype.

Le pas à pas

  1. Ouvre Google AI Studio et passe en mode Build.
  2. Décris ton appli dans la zone de saisie. Exemple : « une appli qui donne 3 idées de Reels à partir d’un mot ».
  3. Regarde l’aperçu : il s’affiche en direct, à côté.
  4. Affine en discutant avec Gemini dans le chat : ajouter une fonction, changer les couleurs, corriger un bug. Si tu veux, l’onglet Code te laisse modifier le code toi-même.
  5. Récupère ton appli : télécharge le code en ZIP, ou synchronise-le avec GitHub.

3 idées d’applis à tester

Ce sont mes idées, pour t’entraîner.

  1. Le générateur d’idées de Reels : un mot-clé, 3 idées de vidéos.
  2. Le calculateur de devis : tu entres ton tarif horaire et le nombre d’heures, il sort le prix.
  3. La checklist du matin : tes 5 tâches du jour, que tu coches.

Le piège

  • En gratuit, tes échanges servent à améliorer les produits de Google. C’est écrit sur la page des prix de l’API : « Used to improve our products : Yes » pour le niveau gratuit. N’y mets pas de données sensibles.
  • La mise en ligne peut être payante. Le bouton de déploiement envoie ton appli sur Cloud Run, le service de Google Cloud, qui peut être facturé selon l’usage. AI Studio te prévient avant si une appli peut coûter.
  • Si tu utilises des modèles payants, des frais peuvent s’appliquer.

Mes 3 conseils

Ce sont mes conseils, pas des règles de Google.

  1. Commence minuscule. Un seul écran, une seule fonction. Tu ajoutes le reste après.
  2. Une demande à la fois dans le chat. Plus facile de voir ce qui a cassé.
  3. Télécharge le ZIP dès que ça marche. Tu gardes une version qui fonctionne.

Combien ça coûte, et en France ?

Google l’écrit : l’utilisation d’AI Studio est gratuite tant que tu ne relies pas de clé d’API payante. La France fait partie des régions où l’API Gemini est disponible.
