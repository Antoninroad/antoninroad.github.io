Ce que c’est

Bitwarden est un gestionnaire de mots de passe dont le code est public sur GitHub. Il range tous tes mots de passe dans un coffre chiffré, les remplit pour toi sur les sites, et t’en crée des solides. Son offre de base est gratuite pour toujours.

Ce que ça change pour toi

  • Dashlane n’a plus d’offre gratuite. Elle s’est arrêtée le 16 septembre 2025. Depuis, un ancien compte gratuit peut seulement exporter ses données.
  • Tout est illimité en gratuit chez Bitwarden : mots de passe illimités, appareils illimités.
  • Partout : extension pour ton navigateur, appli pour ton téléphone, appli pour ton ordi.

Comment l’utiliser

  1. Crée ton compte et installe l’extension de ton navigateur (lien plus bas).
  2. Récupère tes mots de passe enregistrés dans Chrome : dans les réglages des mots de passe de Chrome, « Exporter les mots de passe », au format CSV.
  3. Importe-les dans Bitwarden : dans l’appli web, Outils, puis Importer, et choisis ton fichier. Ensuite, supprime le fichier CSV de ton ordi : il contient tous tes mots de passe en clair.

Le piège : quelques fonctions restent payantes

  • Les codes de double authentification intégrés (les codes à 6 chiffres) sont réservés au Premium : 19,80 $ par an. En gratuit, garde ton appli de codes habituelle.
  • Les pièces jointes et l’accès d’urgence sont aussi en Premium.
  • L’import ne repère pas les doublons : n’importe pas deux fois le même fichier.

Mes 3 conseils

Ce sont mes conseils, pas des règles de Bitwarden.

  1. Importe d’abord ce que ton navigateur connaît déjà. En 5 minutes, ton coffre est rempli.
  2. Choisis un mot de passe principal long, une phrase que toi seul connais. C’est la seule clé de ton coffre.
  3. Change en premier les mots de passe que tu réutilises partout, avec le générateur de Bitwarden.
