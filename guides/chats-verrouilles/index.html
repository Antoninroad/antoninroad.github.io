Comment verrouiller un chat, où le retrouver, et le piège du code oublié qui efface tout.

Ce qui est sorti le 20 octobre

OpenAI a ajouté les chats verrouillés dans ChatGPT. Tu choisis une conversation, tu la verrouilles, et elle disparaît de la vue :

  • de ton historique,
  • de tes chats épinglés,
  • de la recherche dans tes conversations.

Pour la rouvrir, il faut ton code à 4 chiffres. Sur iPhone, Face ID ou Touch ID peuvent le remplacer ; sur Android, le déverrouillage de ton téléphone.

OpenAI le présente comme une façon de garder une conversation sensible hors de vue quand tu partages ton écran ou que tu utilises un appareil partagé.

Comment verrouiller un chat

  1. Ouvre le menu ••• de la conversation.
  2. Choisis Lock chat (le nom peut être traduit dans ton appli).
  3. Confirme.
  4. La première fois, ChatGPT te demande de créer ton code : 4 chiffres, deux fois.

Le chat part alors dans tes chats verrouillés. Il peut falloir un peu de temps pour qu’il sorte aussi des résultats de recherche.

Une fois ton premier chat verrouillé, tu peux aussi démarrer une nouvelle conversation directement verrouillée, depuis l’espace des chats verrouillés.

Où retrouver tes chats verrouillés

Va dans Projets, puis Locked chats. Tape ton code, et choisis la conversation.

L’accès se referme tout seul :

  • Sur téléphone : après 1 minute loin des chats verrouillés, ou 1 minute en arrière-plan.
  • Sur le web : quand tu rafraîchis la page ou fermes l’onglet, et après un moment loin de l’onglet. Un nouvel onglet redemande le code.
  • Partout : le bouton Lock now referme l’accès tout de suite.

Le piège : le code oublié

Lis bien cette partie.

  • Changer ton code (en connaissant l’ancien) ne supprime rien. C’est dans les réglages, partie sécurité (en anglais : Settings, Security and login, Account PIN).
  • Réinitialiser ton code parce que tu l’as oublié supprime définitivement tous tes chats verrouillés, ce que ChatGPT a retenu uniquement dans ces chats, et les fichiers protégés par l’ancien code.
  • Le support d’OpenAI ne peut rien récupérer. Ton administrateur, si tu es sur un compte d’équipe, ne peut pas non plus réinitialiser ton code ni ouvrir tes chats.

Oublier ton code ne supprime rien tout seul. C’est la réinitialisation qui efface tout.

Ce que ça ne fait pas

Verrouiller un chat change où il s’affiche et comment tu l’ouvres. Selon OpenAI, ça ne :

  • chiffre pas la conversation de bout en bout, et ce n’est pas un coffre chiffré à part ;
  • change pas combien de temps OpenAI garde le chat ;
  • change pas ton réglage d’amélioration des modèles ;
  • efface pas ce que ChatGPT avait retenu sur toi avant que tu verrouilles le chat.

Et quelqu’un qui arrive à ouvrir un chat verrouillé peut toujours copier son contenu.

Mes 3 conseils pour ne rien perdre

Ce sont mes conseils, pas des règles d’OpenAI.

  1. Verrouille ce qui parle d’argent et de clients. Devis, tarifs, chiffres, noms de clients : c’est ce que tu ne veux pas voir apparaître pendant un partage d’écran.
  2. Range ton code dans ton gestionnaire de mots de passe. Un code oublié puis réinitialisé, c’est tout perdu, sans retour possible.
  3. Avant de partager ton écran, appuie sur Lock now et regarde tes autres appareils. OpenAI prévient qu’un appareil où ChatGPT est déjà ouvert peut encore afficher le titre du chat tant que sa liste ne s’est pas rafraîchie.

Ce qui ne marche pas encore

Certaines conversations ne peuvent pas être verrouillées :

  • les chats temporaires, archivés ou de groupe ;
  • les chats créés depuis un lien partagé ;
  • les chats avec une tâche programmée, un enregistrement de réunion ou une tâche en arrière-plan ;
  • les conversations Codex.

Autres limites :

  • tu ne peux pas chercher dans tous tes chats verrouillés d’un coup ;
  • un chat verrouillé ne peut être ni archivé, ni épinglé, ni partagé ;
  • si tu verrouilles un chat d’un projet, il sort du projet et perd ses instructions et ses fichiers ;
  • si le chat avait déjà un lien de partage, le verrouiller ne supprime pas ce lien : supprime-le à part ;
  • dans l’appli ordinateur, la voix ne marche pas dans un chat verrouillé.

Tu es en France ?

OpenAI ne donne pas de liste de pays. Ce qui est écrit :

  • Toutes les offres y ont droit : Gratuit, Go, Plus, Pro, et aussi Business, Enterprise et Edu.
  • Ça marche sur le web, dans les applis iPhone et Android, et dans la nouvelle appli ChatGPT pour Mac et Windows.
  • Ça arrive petit à petit. Si tu ne vois pas l’option dans le menu ••• d’un chat, ton compte ne l’a pas encore.

C’est gratuit et ça prend quelques secondes : verrouille tes deux ou trois chats les plus sensibles dès que l’option apparaît.
