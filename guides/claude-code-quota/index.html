Ce que c’est

Dans Claude Code, tape /usage. Sur les forfaits Pro, Max, Team et Enterprise, tu vois ce qui consomme ton forfait :

  • La répartition : la part de chaque skill, sous-agent, plugin et serveur MCP dans ton usage récent, en pourcentage.
  • Des recommandations : une par ligne, dès qu’un poste pèse au moins 10 % de ton usage récent.
  • Tes tâches qui tournent en boucle (/loop), classées par consommation.

Appuie sur d ou w pour passer des dernières 24 heures aux 7 derniers jours. Les chiffres viennent de cet ordi seulement : ton usage sur claude.ai ou un autre appareil n’y est pas.

Le raccourci f

Si le bas de l’écran affiche « f to fix », appuie sur f : Claude Code applique les recommandations qu’il peut appliquer, et te montre chaque changement avant de le faire. Il faut Claude Code v2.1.305 ou plus.

Bon à savoir : un pourcentage indique la part de ton usage concernée par la ligne, pas ce que tu vas économiser.

Mes 3 réflexes

Ce sont mes réflexes. Ils s’appuient sur la doc officielle.

  1. /clear entre deux tâches sans rapport. La doc le dit : un vieux contexte coûte des jetons à chaque message. Et /clear ne coûte rien.
  2. /model pour passer sur Sonnet quand c’est simple. La doc dit que Sonnet gère bien la plupart des tâches de code et coûte moins qu’Opus.
  3. /usage une fois par semaine. Avec w, tu vois tes 7 derniers jours et ce qui a vraiment pesé.

Bonus : /compact suivi d’une consigne (« garde les extraits de code ») résume la conversation en gardant ce que tu veux.

Pourquoi ton quota fond dans une longue session

La doc liste les causes les plus courantes :

  • Un long contexte : toute la conversation est renvoyée à chaque message.
  • Une pause trop longue : ton premier message après la pause relit tout ton contexte.
  • Les tâches programmées et les sous-agents : chacun envoie ses propres requêtes.

Le piège : le forfait

Claude Code n’est pas inclus dans l’offre gratuite de Claude. Il faut au moins Pro : 20 $ par mois au mois, ou 17 $ par mois en annuel (200 $ payés d’avance).
