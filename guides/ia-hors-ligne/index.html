Ce que c’est

Ollama est une appli gratuite et open source (licence MIT) qui fait tourner des IA directement sur ton ordi. Pas sur un serveur au bout du monde : sur ta machine.

Elle fait tourner des modèles ouverts : gpt-oss (le modèle ouvert d’OpenAI), Gemma, Qwen, DeepSeek, Kimi, GLM, MiniMax… C’est l’un des projets les plus suivis de GitHub : 184 609 étoiles le 24 octobre 2026.

Ce que ça change pour toi

  • Pas d’abonnement. Le logiciel et les modèles sont gratuits.
  • Tes documents restent chez toi. Rien ne part sur internet quand tu discutes avec le modèle.
  • Ça marche hors ligne. Une fois le modèle téléchargé, tu peux couper ton wifi. Le guide officiel d’OpenAI montre justement comment « discuter avec lui hors ligne ».

Installer en 3 étapes

  1. Installe Ollama depuis ollama.com/download. Sur Mac, tu télécharges l’appli. Sur Windows, la page te donne une commande à coller dans PowerShell. Sur Linux, une commande à coller dans le terminal.
  2. Télécharge le modèle (une seule fois, il faut internet pour ça). Dans le terminal :
ollama pull gpt-oss:20b
  1. Lance la discussion :
ollama run gpt-oss:20b

Tu poses ta question, il répond. Coupe ton wifi et recommence : il répond toujours.

Le piège : la mémoire

Le modèle gpt-oss-20b est fait pour tenir dans 16 Go de mémoire. Le guide d’OpenAI dit qu’il marche le mieux avec 16 Go ou plus (mémoire de la carte graphique, ou mémoire unifiée sur un Mac récent).

Avec moins, il peut tourner sur le processeur, mais le guide prévient : ce sera plus lent.

Autre limite, et je préfère te le dire : un modèle qui tourne sur ton ordi reste moins fort que les meilleures IA en ligne. Pour un raisonnement très difficile, l’IA en ligne garde l’avantage.

Mes 3 conseils

Ce sont mes conseils, pas des règles d’Ollama.

  1. Garde-le pour tes documents privés. Contrats, factures, notes perso : tout ce que tu n’as pas envie d’envoyer sur un serveur.
  2. Vérifie ta mémoire avant de télécharger. Sur Mac : menu Pomme, puis « À propos de ce Mac ». Moins de 16 Go ? Choisis un modèle plus petit dans la bibliothèque d’Ollama.
  3. Garde une IA en ligne pour les tâches dures. Ollama pour le quotidien et le confidentiel, l’IA en ligne quand il faut de la puissance.

Combien ça coûte, et en France ?

0 €. Ollama est sous licence MIT et gpt-oss sous licence Apache 2.0 : tu peux t’en servir librement. Pas de compte, pas de restriction de pays : tout tourne sur ton ordi. Le seul coût, c’est la place sur ton disque pour le modèle.
